# Annual Stars

[![Tests](https://github.com/phpbbmodders/phpbb-3.1-annualstars/actions/workflows/tests.yml/badge.svg)](https://github.com/phpbbmodders/phpbb-3.1-annualstars/actions/workflows/tests.yml) [![Lint](https://github.com/phpbbmodders/phpbb-3.1-annualstars/actions/workflows/lint.yml/badge.svg)](https://github.com/phpbbmodders/phpbb-3.1-annualstars/actions/workflows/lint.yml)

Shows a star for each year a member has been registered, on their posts and profile.

## Features

- One star per full year of membership, next to each post and on the member's profile.
- Hovering a star shows "N years of membership".
- No settings.

## Requirements

- phpBB 3.3.19 or later
- PHP 7.4 or later

## Installation

1. Copy the extension to `/ext/phpbbmodders/annualstars`
2. In the Administration Control Panel, go to **Customise → Manage extensions**
3. Enable the **Annual Stars** extension
